字幕

优先使用 TED 官方字幕；代码需为 TED 支持的形式（简体中文为 zh-cn）。
0 表示自动（随窗口宽度缩放）。
毫秒 正数=字幕更晚。一般无需设置：扩展会自动补偿片头偏移。若个别演讲仍有偏差，可在此微调。

AI 兜底翻译

当某场演讲没有你目标语言的官方字幕时，用 AI 实时翻译英文（OpenAI 兼容接口，如 DeepSeek / OpenAI / 本地模型）。 默认关闭。翻译结果会本地缓存，避免重复请求。

Key 仅保存在你的浏览器本地（chrome.storage.local），只会发送到你填写的接口地址。

自动识别字幕（语音转写）

连英文字幕都没有的演讲，用语音识别生成字幕。支持两种方式。

需要支持 POST {地址}/audio/transcriptions 的接口（如 OpenAI whisper-1、自建 FunASR）。 DeepSeek / 多数聚合代理不支持，会返回 404。

高级：路径 / 请求头 / 语言

阿里云百炼的识别无法被浏览器直连（WebSocket 不能带 Authorization 头）。请先双击运行 tools/dashscope-relay/start.bat（窗口保持打开），再点下方 测试转发服务（不要点上面的“测试识别接口”）。

音频以几倍速送给百炼（1=实时；过大可能被限流，默认 4）。

纯本地识别（transformers.js + Whisper），无需任何服务或 Key，也只支持英文。 首次使用会下载模型（存到浏览器缓存），之后可离线。CPU 上较慢，长音频需要耐心等。

国内默认 hf-mirror 镜像；也可填 https://huggingface.co

数据 / 缓存

清除所有已保存的字幕文档（官方字幕、语音识别、翻译结果）以及临时缓存。 不会删除你的设置和生词本。
